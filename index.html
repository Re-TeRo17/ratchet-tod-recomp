What it is

Native recompilation, not emulation

The game's code is recompiled into a native Windows program. No emulator is involved.

Your own disc, nothing included

Nothing of the game is shipped. You supply your own copy and the installer prepares it.

Up to 4K, MSAA, 60 fps target

Direct3D 12 rendering, multisample anti-aliasing and a 60 fps target. Press F1 in game for the settings page.

What's new in 1.2.1

  • The PC settings are now in the game's own Options menu, set up automatically at the first start (no extra tools).
  • Real ultrawide: 21:9, 3440x1440 and 32:9 show a wider view instead of a stretched picture; the HUD and menus stay 16:9 in the middle.
  • Armor look and Remove helmet, in F1 and in Options: hide the armor, or keep it and take only the helmet off.
  • Kreeli Comet's ground fog is a soft haze again, as on the PS3.
  • A clearer notice when a new version is available.
  • Aspect ratio and Crop black bars in the F1 settings page.

From 1.2.0

  • Smoother heavy fights: 57 fps on average, far fewer drops below 45.
  • Shaders prepared ahead of time: fewer stutters the first time an effect appears.
  • Fixed: video memory slowly filling up, and problems after Alt-Tab.

Install in 3 steps

  1. Download and unzip

    Get the latest release from GitHub and unzip it anywhere.

  2. Run Install.bat

    Point it to your decrypted disc image (.iso or folder), BCES00052 v1.00.

  3. Run Play.bat

    Start the game.

Requirements

  • Windows 10/11, 64-bit
  • CPU with AVX2, FMA and BMI2 (Intel 4th gen or newer, any Ryzen). A fast 6+ core CPU matters most.
  • Direct3D 12 capable GPU
  • 16 GB RAM
  • About 24 GB of free disk space

FAQ

Which copy of the game do I need?

The European disc, BCES00052 v1.00, as a decrypted .iso or folder. Other regions are not supported yet.

Is anything of the game included?

No. Nothing of the game is included; you need your own copy.

Does it run on Linux / Steam Deck?

The Windows build runs through Proton. See the community guide.

Why does the CPU matter so much?

The game's SPU code runs on your CPU cores, so the heaviest scenes are CPU-limited.

Something went wrong, what do I do?

Open an issue and attach log\tod.log, log\tod_v2_*.jsonl and log\tod_crash.txt. Press F7 in game to mark the moment.
